# 💸 Smart Expense Analyzer PRO

An AI-powered expense analysis dashboard built using Python, Streamlit, Pandas, Plotly, and Machine Learning.

## 🚀 Features

* Upload and analyze expense CSV files
* Interactive charts and visualizations
* Monthly spending trend analysis
* Category-wise expense tracking
* AI-generated expense insights
* Anomaly detection for unusual expenses
* Expense prediction using Machine Learning
* User-friendly dashboard interface

---

## 🛠️ Tech Stack

* Python
* Streamlit
* Pandas
* NumPy
* Plotly
* Scikit-learn

## ⚡ Installation

Clone the repository:

```bash
git clone https://github.com/yathimaxi/smart-expense-analyzer.git
```

Move into the project folder:

```bash
cd smart-expense-analyzer
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
